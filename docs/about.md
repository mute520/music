# 关于我

## 👨‍💻 个人简介

你好！我是一名热爱技术的**前端开发工程师**，专注于构建高性能、用户体验优良的 Web 应用。

我相信，优秀的前端开发不仅仅是还原设计稿，更是通过技术手段将产品的价值传递给用户。我对代码质量有较高的要求，追求简洁、可维护和高性能的实现方式。

## 🛠️ 技术栈

- **核心语言**：HTML5, CSS3, JavaScript (ES6+), TypeScript
- **主流框架**：Vue 3, React, Nuxt.js, Next.js
- **工程化**：Vite, Webpack, pnpm, ESLint, Prettier
- **UI/样式**：TailwindCSS, Sass, Element Plus, Ant Design
- **其他**：Node.js, Git, Docker, CI/CD

## 🌟 项目理念

本站点/项目旨在分享前端开发中的实战经验、记录技术成长轨迹，并为开源社区贡献一份力量。如果你也对前端技术充满热情，欢迎交流！
